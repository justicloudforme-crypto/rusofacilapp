# Заход 7.174 — запись прослушанных вырезок омографов на прод

Здесь лежит всё, чем 214 вырезок уехали в боевую базу и в Blob, и всё,
чем это доказано. **Нового синтеза заход не делал: скрипты не умеют
обращаться ни к какой модели.**

Боевые ключи — только в `.env.turso`, звук и снимки — только вне
репозитория, в `~/rusofacil-listen/`. Строки `AUDIO_BLOB_*` удаляются из
`.env.turso` сразу после записи.

| шаг | чем | что делает |
| --- | --- | --- |
| 0 | `npm run snapshot:prod` | ОДИН снимок боевой базы на все переписи (правило 7.172) |
| 1 | `npx tsx prisma/run-7174/verify-plan.ts --listen=… --folder=… --out=…` | сверка ДО записи: семь утверждений на каждый из 220 файлов, включая «sha256 = прослушанным байтам» и «голос = голосу каста своего предложения». Подсадки: `--plant=место`, `--plant=байты` |
| 2 | `npx tsx prisma/run-7174/snapshot-audio.ts --out=…` | снимок строк `AudioAsset` и отпечаток пар `(id, audioUrl)`; без флага — по локальному снимку (0 боевых чтений), с `--against-prod` — из боевой базы |
| 3 | `npx tsx prisma/run-7174/write-cuts.ts … --dry-run` → `--only=5` → без флагов | запись. `allowOverwrite: false`, `--force` не предусмотрен; замена `audioUrl` — ТОЛЬКО по поимённому `--replace-ids=` |
| 4 | `npx tsx prisma/run-7174/verify-write.ts …` | доказательство: отпечаток прежних строк знак в знак, у каждого нового адреса 200 / `audio/mpeg` / размер до байта / **sha256 ответа = прослушанному**. Подсадка `--plant` |
| 5 | `npx tsx prisma/run-7174/probe-live.ts …` | живая проба анонимом на боевом сайте, два слоя (адрес и настоящий тап), контроль слепоты `--plant` |

`written-7174.jsonl` — журнал записи (210 вставок + 4 замены, у каждой
строки прежний и новый адрес). `held-7174.json` — шесть мест, которые НА
ПРОД НЕ ПОЕХАЛИ: записи метода А вышли не голосом каста своего
предложения (долг 136). Снимок «до» и файл отката — в
`~/rusofacil-listen/7.174/`.
