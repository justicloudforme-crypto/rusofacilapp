# Заход 7.175 — долг 136 голосом каста, «стороны», оговорка эксперимента

**На прод этот заход не записал ни строки и ни одного файла.** Здесь
лежит всё, чем сделаны 8 файлов, положенных владельцу на слух, и всё,
чем это доказано. Синтез был — 7 записей предложений, 479 знаков, — но
он сырьё для вырезки и лежит ВНЕ репозитория, в
`~/rusofacil-listen/7.175/`.

Боевые ключи — только в `.env.turso`, и только на чтение. Ключ Blob в
этом заходе не нужен и не выдавался.

**Главное правило этого захода одно: голос берётся ТОЛЬКО из колонки
`AudioAsset.voice` предложения на свежем снимке прода.** Журнальный ярлык
голоса входом не принимается — из-за него и завёлся долг 136. Держится
сторожем `npm run check:synth-voice-source` (в `verify` и в `ci.yml`).

ровно одно слово и расстояние Левенштейна ≤ 1.

не из журнала (долг 136). Вторая: при отказе выравнивания пробуется
ВТОРАЯ настройка расшифровки — без подсказки. Подсказка текстом
