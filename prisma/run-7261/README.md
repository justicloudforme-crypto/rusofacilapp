# Заход 7.261 — доозвучка `song-katyusha`

Три слова «Ключевой лексики» `song-katyusha` — «расцветать», «яблоня»,
«груша» — до 26.09 держала заморозка, потом — отсутствие разрешения на
запись в прод. 09.10.2026 они синтезированы, приняты аудитом и записаны.

| файл | что делает |
| --- | --- |
| `audit.py` | синтез (`gpt-4o-mini-tts`, `onyx`, mp3) и аудит по правилам 7.165: Whisper `language=ru`, `temperature=0`, клип короче 2 с утраивается через паузу 0,35 с, сравнение по фонетическому ключу. Правило приёма — «услышано ≥ 1 слова, и КАЖДОЕ услышанное — ожидаемое»: Whisper часто схлопывает три повтора в одно слово. Контроль до синтеза — 19 из 19 (10 верных клипов банка приняты, 9 чужих и похожих отвергнуты); `stress_guess` (ударение по громкости слогов) провалил свой контроль — 4 из 13 — и не используется |
| `write-katyusha.ts` | запись: sha256 файла = принятому, ключ `(media, song-katyusha, vocab-<i>)` свободен, путь Blob `audio/media-7261/…` свободен и `allowOverwrite: false`, файл после загрузки сверен до байта (с повтором до ~30 с — сразу после загрузки CDN отвечал 404), затем три строки ОДНОЙ транзакцией |

Порядок запуска:

```
# audit.py — модуль: audit.tts(слово, файл), audit.audit(файл, слово); ключ OpenAI — из .env
npx tsx prisma/run-7261/write-katyusha.ts --listen=~/rusofacil-listen/7.261/принято --dry-run
npx tsx prisma/run-7261/write-katyusha.ts --listen=~/rusofacil-listen/7.261/принято --journal=~/rusofacil-listen/7.261/written.jsonl
```
