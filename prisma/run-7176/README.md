# Заход 7.176 — запись одобренного владельцем и закрытие линии озвучки

Здесь лежит всё, чем семь прослушанных владельцем вырезок уехали в
боевую базу и в Blob, чем закрыт долг 137, и всё, чем это доказано.
**Нового синтеза заход не делал: скрипты не умеют обращаться ни к какой
модели.**

Боевые ключи — только в `.env.turso`, звук и снимки — только вне
репозитория, в `~/rusofacil-listen/`. Строки `AUDIO_BLOB_*` удаляются из
`.env.turso` сразу после последней загрузки.

`written-7176.jsonl` — журнал записи (7 вставок, у каждой строки `id`,
адрес и sha256). Снимок «до» и файл отката — в `~/rusofacil-listen/7.176/`.
Команда отката — в PROGRESS.md 7.176, часть 3.

**Что взято у 7.174 без изменений и почему.** `snapshot-audio.ts` и
`verify-write.ts` — они не про этот заход, а про правило паспорта
(пункты 1, 5 и 6): отпечаток прежних строк и «sha256 ответа прода =
прослушанному». Копировать их сюда значило бы завести вторую копию
правила — ровно тот класс, из-за которого завёлся долг 104.
