# Заход 7.171 — подготовка долгов 131 и 134 к прослушиванию

**Ни одной записи на прод этот заход не делал** — ни в базу, ни в Blob,
ни в код сайта. Здесь лежит всё, чем 220 файлов были сделаны, чтобы
заход 7.172 мог записать одобренное, ничего не переизобретая.

Порядок запуска (из корня репозитория; боевые ключи — только в
`.env.turso`, звуковые файлы и записи — только вне репозитория, в
`~/rusofacil-listen/7.171/`):

| шаг | чем | что делает |
| --- | --- | --- |
| 0 | `npx tsx prisma/run-7171/places.ts --journal=… --list=… --out=…` | сводит 217 мест долга 131 из журнала 7.168 и из ЖИВОЙ боевой базы; пересчитывает номер СЛОВА в номер ТОКЕНА и проверяет каждое место утверждением «токен по новому номеру равен слову» |
| 1 | `python3 prisma/run-7171/part1_debt134.py [--plant]` | долг 134: четыре места, звучавшие чужим вхождением |
| 2 | `python3 prisma/run-7171/part2_metodB.py [--control] [--plant]` | метод Б: перевырезка из уже оплаченной озвучки, синтеза 0 |
| 3 | `python3 prisma/run-7171/part3_metodA.py [--plant]` | метод А: новая запись предложения со знаком ударения, только на остаток после Б |
| 4 | `npx tsx prisma/run-7171/listen-plan.ts …` + `python3 prisma/run-7171/part4_folder.py [--plant]` | папка «на слух»: mp3 в параметрах банка, сквозные номера, `список.txt` |

Общая часть — `common.py` (выравнивание расшифровки на слова
предложения и лесенка полей), `asr.py` (расшифровка, синтез, счётчик
денег), `cut.py` (вырезка из PCM-WAV), `stress.py` (знак ударения и его
сторож с пятью утверждениями).

`places-217.json` и `listen-plan.json` оставлены рядом нарочно: боевая
база в конце захода перестала отдавать чтения (см. 7.171, часть 6), и
без них следующий заход не смог бы повторить разбор.
