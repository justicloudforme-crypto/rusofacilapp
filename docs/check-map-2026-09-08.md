## Что осталось вне CI и почему

**Правило покрывает только то, что гоняет `npm run verify`.** Из 34
именованных команд verify запускает 12; все 12 стоят в CI, кроме одной,
и она названа в списке исключений выше. Остальные 22 в verify не входят
вовсе — их непокрытие это не нарушение правила, а отдельный разговор, и
вот почему каждая группа осталась снаружи.

| группа | команды | почему не в CI |
|---|---|---|
| нужен ЖИВОЙ прод | `check:frozen`, `check:reachability`, `check:internal-links:prod`, `check:word-search:prod`, `check:search-coverage:prod` | адрес существует только после деплоя; их место — отдельный workflow по событию выката, а его сегодня нет вовсе. Прогон каждой 12–15 минут |
| нужны БОЕВЫЕ креды | `check:schema-drift`, `check:glossary-pattern` | против пустой базы CI дают вакуумный зелёный; давать CI боевой ключ сегодня отказ намеренный |
| нужен полный банк | `check:word-search` (в исключениях), `check:crosswords`, `check:search-coverage` | база CI держит восемь строк фикстуры; упирается в долг 64 |
| дорогие по времени | `check:no-db-in-tests` (гоняет весь `npm run test` пять раз, по разу на каждую боевую переменную), `check:lesson-pages` (240 адресов в браузере), `check:story-audio-joins` (читает `public/audio/stories`, которого нет ни в git, ни в CI) | цена шага в разы больше пользы на каждом коммите |
| содержательные аудиты контента | `check:story-audio`, `check:wordgames-clues`, `check:grammar`, `check:lessons`, `check:media-embeds`, `check:sitemap-delta` | у пяти из шести нет позитивного контроля вовсе, а `check:media-embeds` ходит в сеть за чужими видео |

**Единственная из добавленных сегодня, у которой нет своего контроля, —
`check:tokens`.** Её зелёный в CI читать как «не покраснела», а не как
«доказано»; это записано и в самом шаге `ci.yml`.
