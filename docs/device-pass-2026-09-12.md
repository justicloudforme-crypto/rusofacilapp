## Что снимается с телефона как доказательство

Владелец при этом только смотрит и отвечает — команды выполняет агент.

1. Журнал устройства за весь проход: `adb logcat -c` перед стартом,
   затем `adb logcat -v time` в файл `docs/device-logcat-2026-09-12.txt`.
2. Снимки экрана на пунктах 1, 10, 11:
   `adb exec-out screencap -p > docs/device-shot-<N>.png`.
3. Число к пункту 7 — из журнала, по метке запуска
   (`ActivityTaskManager: Displayed com.rusofacilapp.app/.MainActivity`),
   сверх секундомера владельца.
4. Проверка токена оболочки с самого устройства — из журнала webview и
   ответа сервера, а не из конфигурации.
