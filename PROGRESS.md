## Дизайн-система (закрыто)

Направление «Кремль»: **primary `#253B7E`** (индиго) — единственный
кликабельный акцент во всём приложении. **premium-золото** — только
некликабельные маркеры ценности (крон-бейдж, карточка Premium, награды);
enforced скриптом `check:tokens` (падает, если premium-токен встречается
на строке с `onClick=`/`href=`/`<Button`). **folk-red** — отдельный токен
для декоративного/позитивного красного (конфетти, огонёк стрика), не
путать с `danger` (только 2 реальных места ошибок — login/register).
Тёплые нейтрали (кремовая шкала, не холодный графит).

Источник правды: **`tokens.json`** (корень репо) → генерируется в
`src/app/tokens.generated.css` через `scripts/build-tokens.mjs`. Защита:
`npm run check:tokens` (контраст WCAG + запрет premium-на-кликабельном).
Живая галерея всех компонентов: **`/[lang]/styleguide`** (noindex).

## Озвучка (важно, зафиксировано подробно в этой сессии)

**Модель/голос**: `gpt-4o-mini-tts` (OpenAI), голос **`onyx`** — только
мужской, единственный по всему проекту (кроме чтения алфавита в уроках,
там отдельная альтернация — не трогать эту логику без явного запроса).

**Хранилище — двухэтапный pipeline, не «сразу в облако»:**
1. Генерация (`prisma/generate-*-audio.ts`) пишет `.mp3` локально в
   `public/audio/{flashcards,stories,lessons,glossary,idioms,exams}/` +
   строку в `AudioAsset` с временным относительным `audioUrl`.
   Каждый клип проходит аудит: обратная транскрипция Whisper, сверка по
   словам (порог 82%, до 5 попыток).
2. Миграция (`npm run migrate:audio-to-blob`, `prisma/migrate-audio-to-blob.ts`)
   грузит файлы в **Vercel Blob** (отдельный публичный стор,
   `AUDIO_BLOB_STORE_ID`/`AUDIO_BLOB_READ_WRITE_TOKEN` — НЕ тот же токен,
   что приватный стор голосовых ответов студентов) и переписывает
   `AudioAsset.audioUrl` на постоянный `https://<store>.public.blob.vercel-storage.com/...`.

**Источник правды в проде — blob-URL в `AudioAsset`.** `public/audio/` в
`.gitignore` с явным комментарием «generation source/cache only, never
committed» — локальные файлы одноразовые, реальный сайт их не видит.

**ЗОЛОТОЕ ПРАВИЛО ПРОЕКТА (владелец подтвердил, зафиксировать в
CLAUDE.md — ещё НЕ сделано, см. «Следующий шаг» ниже):** озвучиваем один
раз, сохраняем в blob, переиспользуем сохранённый файл. **Никогда** не
генерируем одно и то же дважды (правка текста карточки НЕ триггерит
переозвучку — ключ кэша это `id` записи, не хэш текста; пересоздать
клип можно только явным `--force` для узкого среза). `speechSynthesis`
браузера — **только аварийный fallback** в `SpeakButton.tsx`, если
`audioUrl` не задан или файл не загрузился, никогда не основной путь.

**Озвучены** (счёт по `dev.db`): flashcard 11 356 · story 4 291 ·
lesson 4 258 · idiom 1 542 · glossary 273 · exam 148. Схему БД менять не
нужно — у `FlashcardCard` нет своего поля аудио, связь через
`AudioAsset(contentType="flashcard", contentId=card.id, itemKey="word"|"example")`,
уже заджойнено и закэшировано в `getFlashcardIndex()`
(`src/lib/flashcards/cache.ts`).

**Ключи окружения** (`OPENAI_API_KEY`, `AUDIO_BLOB_STORE_ID`,
`AUDIO_BLOB_READ_WRITE_TOKEN`) — все присутствуют в `.env`.

**Проверено вживую**: `curl -I` на реальный blob-URL слова «привет» →
`200 OK`, настоящий mp3. Для демо-карточек главной страницы аудио уже
существовало — генерации не потребовалось.

## Правила работы (полный текст — в CLAUDE.md)

Mobile-first (375px → 768px → 1280px). Все стили — только через
дизайн-токены. **primary** — единственный кликабельный акцент,
**premium** — только некликабельные маркеры (enforced check:tokens).
Минимальный тач-таргет 44×44px. Capacitor подтверждён — safe-area/
`100dvh`/без `position:fixed` на инпутах/обработка «Назад». Не трогать
бизнес-логику/роутинг/Stripe без явной просьбы. План и остановка перед
крупными структурными изменениями. Каждый шаг — отдельный коммит,
откатываемый одной командой. После каждого шага —
check:tokens/lint/typecheck/тесты/build, затем **живая проверка
владельцем на телефоне**, прежде чем идти дальше.

Полные обоснования — в **AUDIT.md** (база багов/несоответствий) и
**CLAUDE.md** (правила проекта, мобильные особенности Capacitor).
